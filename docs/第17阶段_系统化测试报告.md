# 第17阶段 系统化测试报告

## 1. 测试目的

验证智能胰岛素泵仿真系统在 Spring Boot 启动、Sensor、Analyzer、Alarm、Simulation Dose、PumpCommand、Pump、H2、历史页面、ECharts、AI Agent 和 Fault Simulation 方面的实际可运行性，并验证两个收尾点已经接入真实流程。

## 2. 测试环境

- Windows
- Java 1.8.0_202
- Maven 3.9.11
- Spring Boot 2.7.18
- 项目端口 9100
- H2 文件库：`jdbc:h2:file:./data/insulin_pump_db`

## 3. 测试范围和方法

先执行 `mvn clean compile`，结果为 `BUILD SUCCESS`；然后通过 `mvn spring-boot:run` 启动服务，使用实际 HTTP GET/POST 请求验证接口和页面资源。两个收尾点另有 JUnit/Mockito 单元测试。由于当前工具没有浏览器自动化和截图能力，ECharts 的 HTTP 资源可访问性已验证，但图表视觉渲染需人工打开页面确认。

## 5. 发现的问题

1. 初始代码中 `InsulinCalculator` 未读取历史记录。
2. 初始代码中 `PumpCommand` 仅为模型类，未参与执行。
3. PowerShell 默认输出编码导致中文响应在终端显示乱码，实际 HTTP JSON 字段和状态码正常。
4. 当前执行环境没有浏览器自动化截图工具，因此不能伪造 ECharts 视觉截图。

## 6. 修改内容

- `InsulinCalculator` 注入 `SimulationRecordRepository`，读取最近 5 条记录。
- 近期存在 `simulationDose >= 4.0 SU` 时返回 `HISTORY_LIMIT`，并返回 `historyRecordCount`、`historicalDoseLimitApplied`。
- 新增 `PumpCommandService`，生成并执行 `DELIVER`、`STOP`、`NO_ACTION`，防御未知命令。
- `PumpController` 的输注和停止接口改为通过 `PumpCommandService`，保留原有 API。
- 前端剂量说明显示历史记录数量和历史限制是否触发。
- 增加 `InsulinCalculatorTest`、`PumpCommandServiceTest`。
- 增加本测试报告、全过程总结和 README。
