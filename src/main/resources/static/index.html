第一次使用？按这 4 步操作

所有控制量均为课程软件仿真
1. 采集并分析

点击“采集并分析”，系统读取三类 Sensor 并自动执行 Analyzer、Alarm。

2. 计算控制量

点击“计算仿真控制量”，查看 READY、NO_DELIVERY 或历史限制结果。

3. 执行或跳过

READY 时点击“执行输注”；NO_DELIVERY/HISTORY_LIMIT 时无需执行。

4. 保存结果

完成执行或得到无需输注的决策后，点击“保存本轮记录”。
